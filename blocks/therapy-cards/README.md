# therapy-cards

Custom **cards** block. Purpose: Revenue by therapy area: one bordered card per area with title, growth (green up / red down), revenue figure and description.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: title | growth | figure | description.
