# results-downloads

Custom **custom** block. Purpose: Downloads column of a results release: heading, then one item per document (title + PDF call-to-action), then optional trailing CTAs.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Downloads h2 as default content before the block; one row per document: h3 title + bold link CTA to a PDF; rows without a heading are trailing CTAs.

## Supported variations

No variations.
