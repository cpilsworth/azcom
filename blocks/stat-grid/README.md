# stat-grid

Custom **cards** block. Purpose: Two-column grid of key figures (label, figure, optional change line) in a rounded hairline-divided panel.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per figure: cell 1 label, cell 2 figure, cell 3 change line (optional).
